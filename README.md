# **Maze Solver with Conveyors (สายพานทางเดียว) – Python Version**

## **วัตถุประสงค์**
พัฒนาอัลกอริทึมเพื่อหา **เส้นทางที่สั้นที่สุด** จากจุดเริ่มต้น `'S'` ไปยังจุดสิ้นสุด `'E'` บนตาราง 2 มิติ โดยในเขาวงกตมี **สายพานทางเดียว (Conveyors)** ที่เมื่อผู้เล่นก้าวเข้าไปแล้วจะถูก **เลื่อนไปตามทิศทางของสายพานแบบไม่มีค่าใช้จ่าย (free move)** และสามารถเลื่อนต่อเนื่องได้หากเจอสายพานติดกัน

## **คำอธิบายอินพุต**
- `maze` คืออาร์เรย์ 2 มิติ (grid) ของอักขระ โดยแต่ละช่องมีความหมายดังนี้:
  - `'S'` : จุดเริ่มต้น (มีเพียง 1 จุด)
  - `'E'` : จุดสิ้นสุด (มีเพียง 1 จุด)
  - `'#'` : กำแพง (เดินผ่านไม่ได้)
  - `'.'` : ช่องทางเดิน (เดินผ่านได้)
  - `'>'`, `'<'`, `'^'`, `'v'` : **สายพานทางเดียว** ที่จะเลื่อนไปยังช่องถัดไปตามทิศทางของสัญลักษณ์นั้นทันทีโดย **ไม่เสียก้าว**
    - `'>'` ขวา, `'<'` ซ้าย, `'^'` ขึ้น, `'v'` ลง

### **กติกาการเลื่อนของสายพาน**
1. เมื่อ “ก้าวเข้า” ช่องสายพาน จะเลื่อนไปยัง **ช่องถัดไปตามทิศทาง** ทันทีโดย **ไม่เสียก้าว**  
2. หากช่องถัดไปยังเป็นสายพานอีก จะเลื่อนต่อเนื่องไปเรื่อย ๆ (**ฟรีทั้งหมด**) จนกว่าจะถึงช่องที่ไม่ใช่สายพาน  
3. หากระหว่างการเลื่อนพบว่า **ชนกำแพง** หรือ **อยู่นอกกริด** ให้ถือว่า **ไม่สามารถก้าวเข้าสายพานช่องแรกนั้นได้** (ตัดทางเลือกนั้นทิ้ง)  
4. การก้าวจากช่องปกติไปยังช่องข้างเคียง (4 ทิศ) **คิดเป็น 1 ก้าว** ส่วนการเลื่อนบนสายพานคิดเป็น 0  

---

## **เอาต์พุตของฟังก์ชัน**
- `{"distance": d, "path": [[r0,c0], ...]}`  
- หากไปไม่ถึง: `{"distance": -1, "path": []}`

---

## **เงื่อนไข/ข้อจำกัด**
- ขนาดกริดสูงสุด **100 × 100**
- `'S'` และ `'E'` อย่างละ **1 จุด**
- จำนวนช่องสายพานรวมไม่เกิน **200 ช่อง**
- ต้องคืน **เส้นทางที่สั้นที่สุด** โดยนับเฉพาะก้าว (การเลื่อนบนสายพานมีค่าใช้จ่ายเป็นศูนย์)

---

## **แนวทาง (ไม่บังคับ)**
- ใช้ **BFS/0-1 BFS** หรือ **Dijkstra (น้ำหนัก 0/1)**  
- ก่อนเพิ่มสถานะเพื่อนบ้าน: ถ้าเพื่อนบ้านเป็นสายพาน ให้ **จำลองการเลื่อนฟรีต่อเนื่อง** ไปจนถึงช่องที่ไม่ใช่สายพาน หรือพบว่าเลื่อนไม่ได้ (ติดกำแพง/นอกกริด)

## **ตัวอย่างที่ 1**
```python
# Input
maze1 = [
    ['S', '.', '>', 'E'],
    ['#', '#', '#', '#'],
    ['.', '.', '.', '.']
]

# Output (หนึ่งในคำตอบที่ถูกต้อง)
# เดิน (0,0)->(0,1)->(0,2) = 2 ก้าว, จากนั้นสายพาน '>' พาไป (0,3) ฟรี
# {"distance": 2, "path": [[0,0],[0,1],[0,2],[0,3]]}
```

---

## **ตัวอย่างที่ 2** (เลื่อนต่อเนื่องหลายสายพาน)
```python
# Input
maze2 = [
    ['S', '.', '>', '>', 'E'],
    ['#', '#', '#', '#', '#']
]

# Output
# เดิน 2 ก้าวถึงสายพานแรก แล้วถูกเลื่อนฟรี 2 ช่องไปถึง 'E'
# {"distance": 2, "path": [[0,0],[0,1],[0,2],[0,3],[0,4]]}
```

---

## **ตัวอย่างที่ 3** (ทางที่เข้าไม่ได้เพราะชนกำแพง)
```python
# Input
maze3 = [
    ['S', '.', '>', '#', 'E'],
    ['#', '#', '#', '#', '#']
]

# Output
# เข้า (0,2) จะถูกเลื่อนไป (0,3) ซึ่งเป็นกำแพง → ทางนี้ใช้ไม่ได้ และไม่มีทางอื่นถึง 'E'
# {"distance": -1, "path": []}
```

## **ตัวอย่างที่ 4 (แก้ไขคำอธิบายให้ถูกต้อง)**

> หมายเหตุ: ในผังนี้ `E` อยู่ที่ `[0,4]` และช่อง `[0,3]` กับ `[1,4]` เป็นกำแพง ทำให้ `E` ถูกปิดล้อม จึง **ไปไม่ถึง**

```python
# Input
maze4 = [
    ['S', '.', 'v', '#', 'E'],
    ['#', '#', 'v', '#', '#'],
    ['.', '.', 'v', '.', '.'],
    ['#', '#', '.', '#', '#'],
    ['.', '.', '.', '.', '.']
]

# Output ที่ถูกต้อง
# {"distance": -1, "path": []}
```

---

## **(ตัวเลือกเพิ่มเติม) ตัวอย่างที่ 5 — ผังที่ปรับให้ไปถึง E ได้**
```python
# Input (แก้บางช่องให้เป็นทางเดิน)
maze5 = [
    ['S', '.', 'v', '.', 'E'],
    ['#', '#', 'v', '.', '#'],
    ['.', '.', 'v', '.', '.'],
    ['#', '#', '.', '.', '#'],
    ['.', '.', '.', '.', '.']
]

# เส้นทางอย่างหนึ่ง (นับเฉพาะก้าว): S→…→(0,2)  แล้วเลื่อนฟรีลงมาต่อเนื่องถึง (3,2) จากนั้นเดินไต่ขึ้นกลับไปยัง 'E'
# {"distance": 7, "path": [[0,0],[0,1],[0,2],[3,2],[3,3],[2,3],[1,3],[0,3],[0,4]]}
```
